## Reporting a Vulnerability

We take the security of our project, contributors, and players seriously.

If you discover a security vulnerability, sensitive information leak (such as inadvertently exposed credentials, tokens, or private network addresses), or potential exploit in DEADeye, please report it privately:

1. **Do not open a public GitHub issue.**
2. Send an email to the repository maintainer: `jeyavardhan.dev@gmail.com` (or submit a Private Security Advisory via GitHub's Security tab).
3. Include:
   - A description of the vulnerability or exposed artifact.
   - Specific commit hashes or file paths involved.
   - Steps to reproduce or remediate the issue.

We will acknowledge receipt within 48 hours and work on a prompt remediation release.
